# Humanizer

A skill that removes common AI-writing patterns while preserving meaning and voice.

`SKILL.md` is the canonical behavior spec. Keep detailed pattern definitions and rewrite rules there.

## Usage

Ask your agent to humanize text:

```text
Please humanize this text: [your text]
```

Or invoke directly while editing documents.
