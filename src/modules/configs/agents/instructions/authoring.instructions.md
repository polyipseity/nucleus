## Markdown line wrapping

Do not insert hard line breaks to keep paragraphs under a certain column width. Readability is not a valid reason to ignore this — markdown viewers are responsible for rendering content readably. Hard-wrapping only makes the raw file content worse to navigate and edit.

The only exception is when a validator or linter enforces a maximum line length — in that case, follow the tool's requirement. No other justification for hard-wrapping is valid.
