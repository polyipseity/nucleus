# Nucleus citation reference

Loaded instructions keep the rules. This skill holds the documentation detail they point to.

Load the matching reference when the question needs examples or a lookup:

- `references/citation-quality.md`: source selection, canonical URLs, deprecated APIs.
- `references/documentation.md`: per-file comments, MANUAL files, deterministic JSON, markdown.
- `references/comment-annotations.md`: grammar, check ids, consumers, enforcement.
- `references/embedded-content.md`: platform read paths, tokens, exception classes.
- `references/tooling-and-validation.md`: stack discovery, preflight, step structure, stack specifics.
