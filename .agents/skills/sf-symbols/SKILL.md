# SF Symbol names for Automator workflow icons

## Hard rule: always look up from an authoritative source

Every SF Symbol name must be verified against the macOS SFSymbols private framework, not third-party lists (e.g. `sam4096/apple-sf-symbols-list`), which are often incomplete and can falsely label valid symbols as missing.

## Authoritative sources

| Source | Location | Best for |
| -------- | ---------- | ---------- |
| **SF Symbols app** | Free download from Apple Developer | Visual browsing, search, copy name |
| **macOS private framework** | `/System/Library/PrivateFrameworks/SFSymbols.framework/` | Authoritative; source for the generated list |
| **Generated list** | `~/Library/Application Support/nucleus/state/sf-symbols.txt` | Quick `grep`-based lookup |

The HIG page on developer.apple.com is a design guide, not a catalog — it does not list symbol names. There is no web-based catalog.

## Generated list

`~/Library/Application Support/nucleus/state/sf-symbols.txt` is generated by the `macos-generate-sf-symbols` activation step (`src/platforms/macOS/scripts/macos-generate-sf-symbols.sh`), which runs on every `nucleus-apply` on macOS. It is extracted from the `CoreGlyphs` and `CoreGlyphsPrivate` bundles inside the macOS SFSymbols framework — never downloaded from a third-party source — and it is not committed to the repository.

### Look up a symbol name

```bash
grep -i 'keyword' "$HOME/Library/Application Support/nucleus/state/sf-symbols.txt"
```

### Regenerate by hand

The activation step already regenerates the list whenever macOS updates SF Symbols. To regenerate without a full apply:

```bash
src/platforms/macOS/scripts/macos-generate-sf-symbols.sh \
  /usr/bin/plutil "$(command -v grep)" "$(command -v sort)" "$(command -v cmp)"
```

## Cross-host status

NixOS and Windows: not applicable.

> **WHY:** SF Symbols is an Apple-only API; the SFSymbols framework and its `name_availability.plist` files exist only on macOS. There is no NixOS or Windows equivalent to generate, so the skill and its list are macOS-only by nature, not by omission.

## Visual: SF Symbols app

1. Download and open the SF Symbols app from Apple Developer.
2. Search or browse categories.
3. Select a symbol — its name appears at the bottom.
4. Right-click → "Copy Name".

## Policy reference

The icon convention policy for this project's Automator workflows is documented in `src/hosts/MacBook/services/automator-workflows/default.nix` (header comment section "SF Symbol icon policy").

## macOS version floor

Symbols from SF Symbols 3 require macOS 12 Monterey+. Always check the SF Symbols version in which a symbol was introduced and verify against the host's minimum macOS version.
